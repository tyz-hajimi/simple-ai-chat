# 完整证明文件（P09）— 过程稿

> 严格区分：**已证** / **条件式** / **缺口**。原猜想仍开放。

## 1. 问题重述与符号

**猜想（Sun Conjecture 6.1(i) 首断言）.** 每个整数 $n\ge 2$ 可写成
$$
n=x^4+y^3+z^2+2^k,\qquad x,y,z\in\mathbb{N}_0,\ k\in\mathbb{N}_1.
$$

- $\mathcal{R}=\{x^4+y^3+z^2+2^k\}$（目标集）
- $\mathcal{R}_{4,3,2}=\{x^4+y^3+z^2\}$，$E=\mathbb{N}_0\setminus\mathcal{R}_{4,3,2}$
- $W(N)=\{N-2^k:1\le k\le\lfloor\log_2(N-1)\rfloor\}$
- $\mathcal{F}_0=\{N\ge 2:W(N)\subseteq E\}$
- $\beta=1/4+1/3+1/2=13/12$

## 2. 主要结论（当前可陈述）

### 已证定理（本仓库采纳的骨架 + 本窗口加固）

1. **几乎所有可表（定理 B）.** 由 Roth (1949) 例外集 $|E\cap[1,X]|\ll X/(\log X)^{1/20}$ 与固定 $k=1$，几乎所有 $n\ge 2$ 属于 $\mathcal{R}$。
2. **局部满（定理 A/A′）.** $\mathcal{R}$ 在所列单模及 $63,72$ 上满剩余。
3. **密度不够（L08）.** 存在密度 $0$ 的抽象 $E$ 使 $\mathcal{F}_0$ 无限。
4. **CS 下界.** $|\mathcal{R}\cap[1,X]|\gg_\varepsilon X^{5/6-\varepsilon}$。
5. **次弧子估计（L-Circ-7/8/9；L-Dec-1…5；L-Hua-1…5；L-Lac-1…4,7；L-Biq-1…6；L-Osc-1…6,8；L-Wt-1…6；L-Tri-1…5,7,8；L-Klo-1…6,8,9；L-Fib32-1…8；L-Dual-1…5,7,8；L-Bud-1…8）.** 见引理库；L-Dec-2 将次弧积分改进至 $N^{13/24+\varepsilon}$，距 $N^{1/12}$ 仍差 $N^{11/24}$；L-Hua 凸障碍确认华氏 Hölder 族不能优于 $13/24$；L-Lac Peak/Flat 分裂给出可引用测度引理，但固定弱次弧下无半无条件 $N\ge N_0$；L-Biq 对 $f_4$ Weyl 差分完备化：朴素多重积分指数 $35/48$，回收 $L^4$ 恰 $13/24$，**差分不破凸壁**；L-Osc-2 对振荡 $\Xi$ 给出 $|\Xi|\ll N^{13/24+\varepsilon}K^{1/2}$（强于绝对值 $(\log N)^{1/2}$），L-Osc-3/8 钉死矩方法天花板；L-Wt 引入平滑权 / 短区间混合幂 $F_j$，加权凸性指数仍 $=\beta/2$，**平滑权不改变 $\beta/2$ 凸终点**；L-Tri 把次弧写成三线性型，$T_\psi$：Bourgain-ML / Wooley-EC 均 $E=13/24$，**对角流形障碍**阻止真三线性增益；L-Klo 用 Heath-Brown / Vaughan 型挖出中间弧 $\mathfrak{I}(Q,R)$，贡献 $\ll N^{13/24+\varepsilon}$，但**剩余真次弧指数不能 $<13/24$**，清洗无净 $N^{-\delta}$；L-Fib32 纤维改写 $r=\sum_x r_{3,2}(m-x^4)$，$f_4$ 外置卷积：纯 $(3,2)$-阈值否证，$L^2$ 枝回收 $13/24$，$\|f_4\|_\infty$ 得 $N^{1/3}$ 仍差 $N^{1/4}$；L-Dual 用 Titchmarsh / Plancherel 对偶把 $\int|F|$ 写成表示能量 $\mathcal{E}_2(r)$ / 大值层切 / 对偶和，路径指数均 $13/24$，**对偶能量对角障碍**阻止非凸 $\delta$；L-Bud 把 H-gap $N^{11/24}$ 拆成 $(f_4)/(f_3)/(f_2)/$交叉预算，证明可分模型下单/双因子不可破壁且单线 $\delta$ 不能破 $1/12$（最小破壁组合 MBC-Sep/Fib/Bil/X）；**不**蕴含假设 H 或 H′。
6. **E-kill 规约（L-Ekill-A2-1/2）.** 整窗 $\Leftrightarrow$ 二进差集最大相关；反相关准则 $\Rightarrow\mathcal{F}_0$ 有限（准则对真实 $E$ 未证）。
7. **局部密度（L-Ekill-SS-1）.** $\sigma_p(m)\ge p^{-2}$；无单素数阻碍。
8. **FW 整窗谱检测（L-FW-1…4,7）.** 平凡特征 $|\Phi_N(0)|=K\Leftrightarrow$ 整窗；整窗的低频 Dirichlet 指纹 $|\Phi_N|\gg K^{1-\theta}$；Plancherel 与偏差形式。**不**蕴含 $\mathcal{F}_0$ 有限。
9. **Det 窗归约（L-Det-1/2）.** $\rho_E\le C K^{\theta}$（$\theta<1$）$\Rightarrow\mathcal{F}_0$ 有限$\Rightarrow$ L07；$N\in\mathcal{F}_0$ $\Leftrightarrow$ 多水平 $S_{N-2^k}$ 同时空虚。
10. **奇异级数轨道（L-SSO-1/3/4）.** $\mathfrak{S}_{\le P}$ 模 $M_P$ 周期；窗口为二进乘法轨道采样；单素坏类不能覆盖长于坏弧的连续指数段。
10′. **奇异级数地板（L-Floor；R11→R13）.** 原 L-Floor-1/2「$\inf\mathfrak{S}\ge c>0$ / SSO-G4 框架闭合」已 **R13 否证**（SSO-2(A) 误用 $13/12>1$）。G4 主路改挂 L-Floor-7/8 或 Tail-Weil 下 1♯；**不**蕴含可表 / E-kill。
11. **加性能量链（L-AE-1…3,7）.** 整窗 $\Rightarrow$ $\Delta_K$-团 $\Rightarrow\mathcal{E}_2(E\cap[N/2,N])\gg K^2$；近随机 $\Rightarrow$ 相关 CS 上界。**不**单独蕴含 $\mathcal{F}_0$ 有限（平坦饱和 AE-G1）。
11′. **能量增量构型（L-Inc-1…5,10；R12）.** 整窗 $\Rightarrow$ $\kappa_\Delta=1-o(1)$；富能量模板 $\Rightarrow$ 长 AP/Bohr；二进团本身无 3-AP。**不**单独蕴含 $\mathcal{F}_0$ 有限（需 Inc-NoAP / Flat-Clash；伪随机为信念未证）。
12. **缓增 $x$（L-Slowx-1…5）.** $\mathcal{F}_A\subseteq\mathcal{F}_0$ 但 $|\mathcal{F}_0\setminus\mathcal{F}_A|=o(X)$；Roth/Struct 不使 $\mathcal{F}_A$ 变稀；旁路 A4 止步于 $X^{5/6}(\log X)^{O(1)}$ 障碍。
13. **SS-阈值主弧半边（L-Thr-1/3/5）.** $\mathfrak{J}(m)\asymp m^{\beta-1}$；主弧在 $\mathfrak{S}\ge(\log)^{-A}$ 下 $\gg\mathfrak{S}\,m^{\beta-1}$；已证蕴含 $\mathrm{H}_{\mathrm{thr}}+\mathfrak{S}$ 下界 $\Rightarrow$ 可表。**不**含次弧，$\mathrm{H}_{\mathrm{thr}}$ 未证。
14. **主弧有效化（L-Eff-1…6；R8）.** $r_{\mathfrak{M}}\ge c_0\mathfrak{S}\,n^{1/12}-C_E n^{1/12}(Q^{-\delta_0}+n^{-\eta_0})$（$c_0=\frac12 c_{\mathfrak{J}}$，$Q=n^{\theta_0}$）；条件式 $\mathrm{H}(\delta)+\mathfrak{S}\ge(\log)^{-A}\Rightarrow n\ge N_0(\delta,A)$ 可表。**不是**无条件有效范围；**不**证明 H。
15. **$2$-进像集（L-2adic-1…4,6；R7）.** $U_\nu$ 上立方自同构；$I_\nu$ 满故 $\delta_\nu=1$；窗残 $k\ge\nu$ 同步；禁类强制整窗空。**不**蕴含 $\mathcal{F}_0$ 有限（局部满$\not\Rightarrow$整点可表）。
16. **立方根旁路弱化（L-CRB-1…5；R9）.** DH/Roth 引用表；否证「几乎所有 $y^3+z^2+2^k$」；$z=0$ 切片更稀更硬；短 $k$-窗几乎所有拼合。**一律弱于**原猜想；**不**推进充分大全体。
17. **连续 Fourier 衰减桥（L-EFD-1…4,7；R9）.** Plancherel+Roth 给出 $\int|\widehat{1_E}|^2\ll X/(\log)^{1/20}$，校正目标形 $\ll X^2/(\log)^c$ 过弱；桥引理 $S_E=\int\widehat{1_E}\,e(-N\alpha)\,g_N$；平凡次弧 CS $\ll(|E|K)^{1/2}$ 过大；整窗 $\Rightarrow|\mathrm{Dev}_E|\ge K/2$。**不**蕴含 $\mathcal{F}_0$ 有限。正交于 L-FW（$m$-谱 vs $k$-谱）。
18. **多项式缺项弱化（L-Poly-1…5；R13）.** 一次 $P(t)=at+b$ ⇒ 充分大全体（L-Poly-2）；$P(t)=t$ 平凡；$t^2$ 冗余几乎所有且凸壁不闭全体；$t!$ 不救密度零切片；lacunary $\{2^k\}$ 与多项式有界间隙本质不同。**一律弱于**原猜想；**不**推进 $2^k$ 充分大。
19. **大筛二进窗（L-LSW-1…5,9；R14）.** 二次型 $Q=\sum_N|\sum_k 1_E(N-2^k)c_k|^2$ 的 Parseval/CS 大筛界；整窗下界 $\Rightarrow|\mathcal{F}_0\cap I_K|\le|E\cap[1,2^{K+1}]|$；Roth 下 $|\mathcal{F}_0\cap[1,X]|\ll X/(\log X)^{1/20}$（**可仍无限**）。条件式 LSW-Corr / Flat / Sum$\Rightarrow$更强计数或有限（L-LSW-6…8）。正交于 FW/EFD/AE/Pack。
20. **短二进窗几乎所有（L-SIA-1…6；R15）.** Roth 例外集 + 窗长：几乎所有 $n$ 在短窗 $I(n;\theta)=\{k:K-K^{\theta}\le k\le K\}$（$\theta\in(0,1]$）内可表，且比例击中 $(1-o(1))$（L-SIA-3/5）。强化 Thm-B / L-Bin-5 / L-CRB-5；**不达**充分大全体。
21. **Roth 二进双点相关（L-RShift-1…3,6(A),7；R16）.** 次弧 $R_{\mathfrak{m}}(h)=\int_{\mathfrak{m}}|F|^2 e(h\alpha)$；Roth 均值平方 $\not\Rightarrow$ LSW-Corr；主弧误差同步、次弧 CS 无亏缺——**不**阻碍 $m$ 与 $m+2^k$ 同时例外。条件式 Osc/Mom$_4$/SS$\Rightarrow$近 LSW-Corr（L-RShift-4…6）。**不**蕴含 $\mathcal{F}_0$ 有限。
22. **立方–平方差集结构（L-CSdiff-1…6,8；R15）.** $\mathcal{R}-\mathcal{R}=\{x^4-{x'}^4\}+(\mathcal{S}-\mathcal{S})$；$\square-\square\subseteq\mathcal{S}-\mathcal{S}$（$n\not\equiv 2\pmod 4$）；$K\ge 4\Rightarrow\Delta_K\subseteq\square-\square\subseteq\mathcal{S}-\mathcal{S}$（全体）；$\mathcal{S}$ 薄而 $\mathcal{S}-\mathcal{S}$ 厚（密度 $\ge 3/4$）；整窗 $\Rightarrow\Delta_K\subseteq(E-E)\cap(\mathcal{S}-\mathcal{S})$。**不**单独蕴含 $\mathcal{F}_0$ 有限。
