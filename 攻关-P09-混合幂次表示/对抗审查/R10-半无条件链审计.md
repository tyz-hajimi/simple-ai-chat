# P09 对抗审查 · R10-Semi-Uncond-Audit（半无条件拼链）

> 角色：对抗审查智能体。对象：拼链  
> $$
> \mathrm{L\text{-}Thr\text{-}3}+\mathrm{L\text{-}Eff\text{-}4}+\mathrm{L\text{-}SSO\text{-}5}+\mathrm{L\text{-}Ekill\text{-}SS\text{-}2}.
> $$  
> 压力点：是否被误写成「差不多证明了充分大」。  
> 判决档：`通过` / `需降级` / `否证`。不削弱骨架 Thm-A/A′/B、L07、L08、CS-弱；原猜想保持开放。

---

## 0. 指控句与审查标准

**被审指控（宣传形）.**  
「L-Thr-3 + L-Eff-4 + L-SSO-5 + L-Ekill-SS-2 已拼好半无条件链，故差不多证明了充分大。」

**审查标准.**

1. 每步写出**传入条件名**与**传出断言**；不得把条件式结论改写成无条件。  
2. 「半无条件」仅允许 $=$「主弧无条件半边 + 次弧假设 $\Rightarrow$ 有效范围」（L-Eff-4 / L-Eff-6 自承）；不得 $=$ L-Lac-7 所否证的「弱次弧下显式 $N\ge N_0$」。  
3. 「充分大」须标明是：圆法点态可表 / $\mathcal{F}_0$ 有限 / $x=0$ 型 / 原猜想——四者不可混用。

## 1. 逐步条件名传递

### 1.1 L-Thr-3（已证蕴含）

| 方向 | 条件 / 断言 | 名称 |
|------|-------------|------|
| 入 | 次弧 $\lvert r_{\mathfrak{m}}\rvert\le m^{\beta-1}/(\log m)^{A+1}$ | $\mathrm{H}_{\mathrm{thr}}(A)$ |
| 入 | $\mathfrak{S}(m)\ge(\log m)^{-A}$ | $\mathfrak{S}$-对数地板 |
| 出 | $m\in\mathcal{R}_{4,3,2}$（$m\ge m_2(A)$） | 点态可表 |
| 状态 | 箭头已证；$\mathrm{H}_{\mathrm{thr}}$ **开放**（Thr-G1） | — |

合写：
$$
\mathrm{H}_{\mathrm{thr}}(A)+\bigl[\mathfrak{S}(m)\ge(\log m)^{-A}\bigr]
\ \Longrightarrow\ 
m\in\mathcal{R}_{4,3,2}\quad(m\gg_A 1).
$$

### 1.2 L-Eff-4（条件式有效化）

| 方向 | 条件 / 断言 | 名称 |
|------|-------------|------|
| 入 | $\int_{\mathfrak{m}}\|F\|\ll n^{1/12-\delta}$ | $\mathrm{H}(\delta)$（**严于** $\mathrm{H}_{\mathrm{thr}}$） |
| 入 | $\mathfrak{S}(n)\ge(\log n)^{-A}$ | 同 $\mathfrak{S}$-地板 |
| 出 | $n\in\mathcal{R}_{4,3,2}$（$n\ge N_0(\delta,A)$） | **显式门槛**可表 |
| 状态 | 形式 $N_0$ 可定义；无 $\mathrm{H}$ 则 $C_{\mathrm{H}},n_{\mathrm{H}}$ 不存在 | — |

合写：
$$
\mathrm{H}(\delta)+\bigl[\mathfrak{S}(n)\ge(\log n)^{-A}\bigr]
\ \Longrightarrow\ 
n\in\mathcal{R}_{4,3,2}\quad\bigl(n\ge N_0(\delta,A)\bigr).
$$

**传递警告.** L-Eff-4 与 L-Thr-3 **不是**同一前置：前者吃 $\mathrm{H}(\delta)$，后者吃 $\mathrm{H}_{\mathrm{thr}}(A)$。拼链若写「Thr-3+Eff-4」却只标一个次弧假设，则条件名漏标。$\mathrm{H}_{\mathrm{thr}}$ 版显式门槛是 **L-Eff-5**（$N_0^{\mathrm{thr}}(A)$），不应偷换成 L-Eff-4。

### 1.3 L-SSO-5（条件式 G-SS）

| 方向 | 条件 / 断言 | 名称 |
|------|-------------|------|
| 入 | 大 $p$ 坏类比例 $\le 1-\kappa$ | LS（SSO-G2） |
| 入 | 极小 $\Rightarrow$ 有限素集鸽笼 | AP（SSO-G3） |
| 出 | 无连续 $\ge c\log n$ 段 $\eta_0$-极小；接口 $\max_k\mathfrak{S}(n-2^k)\gg 1$ | 弱 $\max\mathfrak{S}$ |
| 状态 | 蕴含可保留；**不**含 SS-阈值、**不**含可表 | — |

### 1.4 L-Ekill-SS-2（条件式）

| 方向 | 条件 / 断言 | 名称 |
|------|-------------|------|
| 入 | $\exists A:\ \mathfrak{S}(m)\ge(\log m)^{-A}\Rightarrow m\in\mathcal{R}_{4,3,2}$ | SS-阈值（$=$ SSO-G5） |
| 出 | $N\in\mathcal{F}_0$ 充分大 $\Rightarrow\max_{k\le K/2}\mathfrak{S}(N-2^k)\ll_A(\log N)^{-A}$ | 坏窗 $\mathfrak{S}$-同步上界 |
| 状态 | 阈值由 L-Thr-3 在 $\mathrm{H}_{\mathrm{thr}}$ 下填充；全阈值开放 | — |

### 1.5 拼合后真实传出（条件式）

在 **同时** 承认 $\mathrm{LS}+\mathrm{AP}+\mathrm{H}_{\mathrm{thr}}(1)$（或 $\mathrm{H}(\delta)$ + L-Eff-4 版）时：
$$
\max\mathfrak{S}\gg 1
\ \stackrel{\mathrm{L\text{-}Thr\text{-}3}}{\Longrightarrow}\ 
\text{某窗点可表}
\ \Longrightarrow\ 
\mathcal{F}_0^{\mathrm{kill}}\text{ 有限}
\ \stackrel{\mathrm{L07}}{\Longrightarrow}\ 
x=0\text{ 型充分大}.
$$
对偶地，SS-阈值 + L-Ekill-SS-2 给出坏窗上 $\max\mathfrak{S}\ll(\log)^{-A}$，与 L-SSO-5 的 $\gg 1$ **冲突**，同得 $\mathcal{F}_0^{\mathrm{kill}}$ 有限。

**未传出：** 原猜想充分大；无条件 $n\ge N_0\Rightarrow n\in\mathcal{R}_{4,3,2}$；无条件 $\mathcal{F}_0$ 有限。

## 2. 蕴含图与最短缺口路径

### 2.1 蕴含图（实线 = 已证箭头；虚线 = 条件式载荷）

```text
                    ┌──────────────┐
                    │  LS + AP     │  (虚: SSO-G2, G3)
                    └──────┬───────┘
                           │ L-SSO-5
                           ▼
                    max 𝔖 ≫ 1
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
        │    ┌─────────────▼─────────────┐    │
        │    │ H_thr(A) 或 H(δ)          │    │
        │    │ (虚: Thr-G1)              │    │
        │    └─────────────┬─────────────┘    │
        │                  │                  │
        │         L-Thr-3 / L-Eff-4·5         │
        │                  ▼                  │
        │         SS-阈值                   │
        │      𝔖≥(log)^{-A} ⇒ ∈ℛ            │
        │                  │                  │
        │                  │ L-Ekill-SS-2     │
        │                  ▼                  │
        │     坏窗 max 𝔖 ≪ (log)^{-A}        │
        │                  │                  │
        └────────► 冲突 ◄──┘                  │
                    │                         │
                    ▼                         │
            ℱ₀^{kill} 有限 ───────────────────┘
                    │ L07
                    ▼
            x=0 型充分大          ✗ 原猜想充分大
```

主弧半边（已证，支撑 L-Thr-3 / L-Eff）：
$$
\mathfrak{S}\ge(\log)^{-A}
\ \stackrel{\mathrm{L\text{-}Thr\text{-}1}/\mathrm{L\text{-}Eff\text{-}1\text{–}2}}{\Longrightarrow}
r_{\mathfrak{M}}\gg \mathfrak{S}\,m^{\beta-1}.
$$

### 2.2 最短缺口路径（标 ★）

从「当前已证库」到「任何像样的充分大结论」，**最短未闭链**是：

$$
\boxed{\star\ \mathrm{Thr\text{-}G1}:\ \mathrm{H}_{\mathrm{thr}}(A)\ \text{（或 }\mathrm{H}(\delta)\text{）}}
$$

理由：

1. **单缺口可达 SS-阈值.** Thr-G1 + 已证 L-Thr-3 $\Rightarrow$ SSO-G5 / L-Ekill-SS-2 前置闭合。轨道侧尚可暂缺。  
2. **同级硬度.** L-Thr-5：已证次弧 $m^{13/24}$ 距 $\mathrm{H}_{\mathrm{thr}}$ 差 $m^{11/24}$；故 Thr-G1 $\asymp$「圆法充分大可表」硬度核，**不是**比充分大弱一档的免费中间式。  
3. **到 $x=0$ 型还需第二缺口.** 最短「杀窗」路径为
   $$
   \mathrm{Thr\text{-}G1}\ +\ (\mathrm{LS}+\mathrm{AP})
   \ \longrightarrow\ 
   \mathcal{F}_0^{\mathrm{kill}}\text{ 有限}
   \ \longrightarrow\ 
   x=0\text{ 型}.
   $$
   其中 Thr-G1 仍是圆法侧唯一瓶颈；LS+AP 为轨道侧最短附加载荷（不可被 L-Eff-4 替代）。  
4. **到原猜想仍有末端缺口.** L07 只输出 $x=0$ 型；原猜想允许 $x>0$，本拼链**无路径**。

**次短缺口（常被漏标）.**

| 代号 | 内容 | 若不补 |
|------|------|--------|
| SSO-G2/G3 | LS+AP | L-SSO-5 不发火，$\max\mathfrak{S}\gg 1$ 不可用 |
| Eff 前置错配 | 用 L-Eff-4 却只假设 $\mathrm{H}_{\mathrm{thr}}$ | 应改引 L-Eff-5 |
| SSO-G4 | $\gg 1\to(\log)^{-c}$ | 弱 $\max\mathfrak{S}$ 对「多数点对数小」图景无杀伤（R4 已降级） |

## 3. 「差不多证明了充分大」是否误写？

### 判决：**是误写（需降级）**

| 宣传读法 | 实际逻辑 |
|----------|----------|
| 四引理拼好 $\approx$ 充分大将至 | 四引理只装配**条件式导管**；导管入口 Thr-G1 与出口「原猜想」皆未接 |
| L-Eff-4 的 $N_0$ $=$ 已有无条件门槛 | $N_0(\delta,A)$ 内含 $C_{\mathrm{H}},n_{\mathrm{H}}$；无 H 则公式空转（L-Eff-4 自承） |
| 半无条件已绕过次弧墙 | 与 L-Lac-7 相反：半无条件**假定**次弧假设；L-Lac-7 否证的是「弱次弧无 H 时的 $N_0$」 |
| L-SSO-5 已服务 E-kill | R4 结论仍有效：无 SS-阈值时 $\max\mathfrak{S}\gg 1$ 对可表/整窗**无效**；阈值 $=$ Thr-G1 |
| 拼链闭合原猜想 | 最多条件式 $x=0$ 型；原猜想开放 |

**允许保留的正确弱句（降级后）：**

> 主弧半边与蕴含箭头已就绪；在假设 $\mathrm{H}_{\mathrm{thr}}(A)$（或 $\mathrm{H}(\delta)$）下，SS-阈值对 $m\ge m_2$（或 $n\ge N_0$）成立；再叠加 LS+AP，得条件式 $\mathcal{F}_0^{\mathrm{kill}}$ 有限并经 L07 得 $x=0$ 型充分大。**不**声称 Thr-G1、LS、AP 或原猜想已证。

## 4. 分条压力测试

### 4.1 L-Thr-3 — **通过**

蕴含计算（主弧下界压过次弧假设）正确。风险仅在外部把「已证蕴含」读成「已证充分大」。L-Thr-6 的非声称句应升格为拼链总禁令。

### 4.2 L-Eff-4 — **需降级**

| 原表述风险 | 降级后 |
|------------|--------|
| 「半无条件拼接给出充分大有效范围」 | 「**假定** $\mathrm{H}(\delta)$ 后的条件式 $N_0(\delta,A)$」 |
| 与 L-Thr-3 并列暗示同一前置 | 标清：Eff-4 吃 $\mathrm{H}(\delta)$；$\mathrm{H}_{\mathrm{thr}}$ 对口是 Eff-5 |
| 对比 L-Lac-7「已突破」 | **不冲突也不突破**：Lac-7 无 H；Eff-4 有 H |

### 4.3 L-SSO-5 — **需降级**（维持 R4）

$\max\mathfrak{S}\gg 1$ 强于 $(\log)^{-1}$，故**在** $\mathrm{H}_{\mathrm{thr}}(1)$ 下可喂 L-Thr-3；但 LS+AP 未关，且无阈值时对 E-kill 无效。禁止写「轨道侧已差不多」。

### 4.4 L-Ekill-SS-2 — **通过**（条件式）

陈述精确：输出是坏窗上 $\mathfrak{S}$ 的上界，不是可表性。误用模式是把「若阈值则坏窗同步小」读成「已证坏窗同步小」。

## 5. 安全并入边界（本轮）

1. **可保留：** L-Thr-1/3/5；L-Eff-1/2/6；L-SSO-1/3/4；L-Ekill-SS-1；各文件内「条件式 / 不声称原猜想」标记。  
2. **必须降级标签：**  
   - 「半无条件拼链 ≈ 充分大」；  
   - 「L-Eff-4 给出无条件 $N_0$」；  
   - 「L-SSO-5 已对接 E-kill」（缺 Thr-G1 时）。  
3. **禁止写入完整证明的跳步：**  
   - 跳过 $\mathrm{H}_{\mathrm{thr}}$/H 宣称 SS-阈值；  
   - 由 $\max\mathfrak{S}\gg 1$ 直接推窗点可表；  
   - 由本拼链推原猜想充分大（L07 末端也不够）。

## 6. 下一轮应开的全新路线（建议 ×2）

**R11-SS-Floor-Orbit（奇异级数轨道地板 / SSO-G4 专攻）.**  
一句话：与次弧阈值脱钩，在截断 Euler 积 + 二进乘法轨道上，把 L-SSO-5 的 $\max\mathfrak{S}\gg 1$ **升至** $\max\mathfrak{S}\gg(\log n)^{-c}$，目标弱 SS-Sync，使即便只有部分阈值也能对「对数小」坏窗图景起杀伤。  
目标引理形：
$$
\exists\,c>0:\quad
\mathrm{LS}+\mathrm{AP}+\text{（轨道乘性输入）}
\ \Longrightarrow\ 
\max_{k\le K}\mathfrak{S}(n-2^k)\gg(\log n)^{-c}.
$$

**R11-Fiber-32-Threshold（$(3,2)$-纤维阈值）.**  
一句话：写 $m=x^4+t$、$t\in\mathcal{R}_{3,2}$，用二次–三次圆法/局部密度控制纤维 $r_{3,2}(m-x^4)$，将 $\mathrm{H}_{\mathrm{thr}}$ 弱化为「对多数 $x$ 的纤维次弧」或「短和中的三次–二次生成函数」，开辟异于全混合 $F=f_4f_3f_2$ 凸壁的阈值路径。  
目标引理形：
$$
\exists\,A,N_0:\ 
\mathfrak{S}(m)\ge(\log m)^{-A}
\ \Longrightarrow\ 
\sum_{x\le m^{1/4}}r_{3,2}(m-x^4)>0
\quad(m\ge N_0),
$$
且次弧输入只要求纤维级估计（允许弱于全 $F$ 的 $\mathrm{H}_{\mathrm{thr}}$）。

## 7. 本轮结论

拼链四箭头的**导管语义**成立，但「差不多证明了充分大」是**误写**：最短缺口 ★Thr-G1 与圆法充分大同级；L-Eff-4 只改写门槛记号；L-SSO-5 仍背 LS+AP 且无阈值时不杀窗；闭合后经 L07 亦仅 $x=0$ 型。半无条件 $=$ 主弧已证 + 次弧假设下的条件式有效范围，**不是**充分大的近终点。
