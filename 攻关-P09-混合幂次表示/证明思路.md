# 证明思路（双主攻）

## P1 = E-kill-1
证明真实例外集 $E$ 上失败集 $\mathcal{F}_0=\{N\ge 2:W(N)\subseteq E\}$ 有限。

旁路：Struct-E、SS-Sync、Pack、二进平移相关、**R9-Cubic-Root-Bypass**（弱化非原猜想：DH/Roth 引用表；否证「几乎所有 $y^3+z^2+2^k$」；$z=0$ 切片更硬；短 $k$-窗几乎所有拼合；见 L-CRB）、**R8-Triple-Window-Pack**（邻窗/倍窗装填 L-Pack-3…6 已证；Mix-Link+Clash$_*$+Roth$\Rightarrow\mathcal{F}_0$ 有限为条件式，显式避开 L08；见 L-Pack）、**R7-2adic-Lift**（$I_\nu=\{x^4+y^3+z^2\bmod 2^\nu\}$；已证 $\delta_\nu=1$，窗 $k\ge\nu$ 同步；无 $2$-进强制整窗；**不**替代反整窗伪随机）、**R1-Fourier-Walsh**（$\Phi_N(\alpha)=\sum_k 1_E(N-2^k)e(\alpha k)$；低频均匀性 FW-Unif $\Rightarrow\mathcal{F}_0$ 有限）、**R1-Det-Surface**（BP/HB 行列式；条件式 $\rho_E\le C K^{\theta}\Rightarrow$ L07）、**R2-SS-Orbit**（$\{\mathfrak{S}(n-2^k)\}$ 二进乘法轨道；截断几乎周期 + 条件式 G-SS）、**R2-Additive-Energy**（$\mathcal{E}_2(E\cap[N/2,N])$；近随机 + AE-Corr/Jump / BW–Sanders 二分 $\Rightarrow\mathcal{F}_0$ 有限；仅近随机不够，见 AE-G1）、**R3-Diff-Eq-Diophantine**（方程 $f(\mathbf{u})-f(\mathbf{v})=2^a(2^b-1)$；已证 $\mathcal{N}_D\ll_{\varepsilon} X^{7/6+\varepsilon}$；条件式 Diff-Out$_\eta\Rightarrow\mathcal{F}_0$ 有限）、**R4-Slow-x**（旁路 A4：缓增 $x\le(\log N)^A$ 失败集 $\mathcal{F}_A$；已证 $\mathcal{F}_A\subseteq\mathcal{F}_0$ 但 $|\mathcal{F}_0\setminus\mathcal{F}_A|=o(X)$，不能破「有界 $x$」阻断；勿与 Gap 的 $R^{(2)}$ 混淆）、**R5-Local-Threshold**（SS-阈值：已证主弧 $r_{\mathfrak{M}}\gg\mathfrak{S}\,m^{\beta-1}$ + 已证蕴含 $\mathrm{H}_{\mathrm{thr}}+\mathfrak{S}$ 下界 $\Rightarrow$ 可表；次弧 $\mathrm{H}_{\mathrm{thr}}$ 未证，见 L-Thr）、**R8-Major-Effective**（服务半无条件拼接：显式 $r_{\mathfrak{M}}\ge c_0\mathfrak{S}\,n^{1/12}-O(\mathrm{误差})$，追踪 $c_0,Q$；条件式 $N_0(\delta,A)$，见 L-Eff；**不是**原猜想）。

## P2 = 假设 H
给出次弧上可发表部分界（L-Circ-6 拆分；Lac 仅当强于 $|g|\le K$）。
**R1-Bilinear-Decouple** 达 $N^{13/24}$；**R2-Hua-Cube** 以华氏 $L^4$ 扫描 Hölder 三元组，凸障碍确认不能优于 $13/24$（H 仍未证）。
**R4-Lac-Peak-Split**：$\mathrm{Peak}=\{|g|\ge K^{1/2+\delta}\}$ / Flat 分裂（L-Lac-1/2）；Flat 仅得 $(\log N)^{1/2-\delta}$ 杠杆，固定弱次弧 $\theta>0$ 下**无**半无条件 $N\ge N_0$（L-Lac-7）；H′ 需几乎-H 的 $F$ + Peak-Maj（Lac-G1/G2）。
**R5-Minor-Oscillation**：振荡 $\Xi=\int_{\mathfrak{m}}Fge(-n\alpha)$；已证 $|\Xi|\ll N^{13/24+\varepsilon}K^{1/2}$（L-Osc-2，强于绝对值 $K$ 因子）；Hölder–矩 / 双线性 / Weyl 均钉死同一天花板（L-Osc-3…5）；要 $N^{13/24-\delta}$ 需 Osc-G1/G2（lacuna 非对角）或 Peak-Maj（**不**声称 H 已证）。
**R6-Biquadrate-Completion**：Weyl 差分 $|f_4|^2\ll P_4\sum_h|S|$ 后与 $f_3,f_2$ 多重积分；朴素路径 $N^{35/48}$，回收 $L^4$ 恰 $13/24$；**差分不破凸壁**（L-Biq-5）。
**R7-Weighted-Beta**：平滑权 $w(x)w(y)w(z)$ / 短区间混合幂定义加权 $F_j$；加权凸性指数仍 $=\beta/2=13/24$；**平滑权不改变 $\beta/2$ 凸终点**（L-Wt-4）。
**R10-Trilinear-Forms**：次弧积分改写为三线性型 $T_\psi(a,b,c)$；**Bourgain-ML** / **Wooley-EC** 可执行路径均得 $E=13/24$；**三线性限制在对角流形 $x^4+y^3+z^2$ 上的障碍**（法向共线 / 对角饱和 / 可分因子化）钉死凸壁（L-Tri-5）；破壁需 Tri-G1–G3（**不**声称 H 已证）。

## 明确阻断
1. 密度 $o(X)$ + 窗口 $\log n$ $\Rightarrow$ 全体（L08）
2. 分模满 $\Rightarrow$ 乘积模同步满（一般假）
3. 有界 $x$ 的 CS $\Rightarrow$ 几乎所有（$\mathcal{S}$ 密度零）；**缓增** $x\le(\log N)^A$ 同阻（L-Slowx-2/3）
4. 条件式当无条件定理
5. 缺项免费闭合 H
6. 先证充分大 $\in\mathcal{R}_{4,3,2}$（更硬）
7. 「几乎所有 $n=y^3+z^2+2^k$」由 DH 推出（L-CRB-2 否证：密度零；DH 要求 $\beta>1$）
8. 固定 $z=0$ 简化原猜想（L-CRB-3：$\beta=7/12$，像集更稀、更硬）
