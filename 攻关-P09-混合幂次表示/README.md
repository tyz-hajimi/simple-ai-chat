# 攻关：孙智伟悬赏猜想 P09

每个整数 $n\ge 2$ 可写成
$$
n=x^4+y^3+z^2+2^k,
$$
其中 $x,y,z\in\mathbb{N}_0$，$k\in\mathbb{N}_1$。

- 出处：Sun, Nanjing Univ. J. Math. Biquarterly 34 (2017), Conjecture 6.1(i)
- OEIS: A280356；Hou 验证至 $10^9$（信任主页，本仓库禁止数值穷举）
- 奖金：$234（主页）

## 双主攻
- **P1 E-kill-1**：真实 $E=\mathbb{N}_0\setminus\mathcal{R}_{4,3,2}$ 上 $\mathcal{F}_0$ 有限
- **P2 假设 H**：次弧 $\int_{\mathfrak{m}}|f_4f_3f_2|\ll n^{1/12-\delta}$ 的可引用弱形式

原猜想仍开放；条件式/几乎所有不得写成已证原猜想。
